cancho-plot

Plots as a command line an agent can read. A table goes in on standard input; an SVG, or the same chart as text, comes out. Written in cancho, in the family of table, ml and stats.

table --format csv ... | plot --x day --y net,margin --with lines --term svg --title "Net margin" > net.svg
table --format csv ... | plot --x day --y net --term dumb          # the same chart as text
Byte-stableThe same table and flags give the same bytes: no clock, no random, no ids. Labels are written from integers, never from float formatting.
Errors are dataA refusal is one JSON line on standard error with a rule tag such as plot.not-numeric, and exit status 2. No input reaches a crash.
Little authorityIt reads standard input and writes standard output. No file, no network, no clock: the compiler checks that the program can do nothing else.
Tested against a second implementationEvery chart in the gates is also drawn by an independent program in exact arithmetic, and mutants of the source must make a gate fail.

What is there, and what is not

Built: points and lines, bars with text categories (grouped for several series), error bars (--yerr), up to five series, a title, markers (--vline, --hline), bands (--band) and the diagonal (--diag), as SVG or as text. Intervals by their ends (--ylo, --yhi), text categories on points (--categories), and the JSON of stats and ml read directly (--json PATH). Histograms (--with hist, from the edges and counts of stats describe). Box plots (--with box). Heatmaps (--with heat --z). Not built yet: ROC and other curves, --logy, a gnuplot-like script, PNG. The plan for the statistics and machine-learning charts is section 19 of the design. The design, with what was measured and what was only chosen, is docs/design.md.
